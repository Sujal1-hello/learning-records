==============================
DAY 6 - OOP CONCEPTS NOTES
==============================

1. Class
- A blueprint for creating objects.

2. Object
- An instance of a class.

3. Encapsulation
- Wrapping data and methods together.

4. Inheritance
- One class inherits another class properties.

5. Polymorphism
- Same method behaves differently.

6. Abstraction
- Hiding implementation details.

Advantages of OOP:
- Reusability
- Better organization
- Easier maintenance
