====================================
DAY 6 - JAVA OOP CONCEPTS NOTES
====================================

1. Class
- A class is a blueprint used to create objects.
- It defines data members and methods.

Real-life example:
Car blueprint before manufacturing.

------------------------------------

2. Object
- An object is an instance of a class.
- Objects can access class properties and methods.

Example:
Student s1 = new Student();

------------------------------------

3. Encapsulation
- Combining data and methods into a single unit.
- Protects data using private access modifiers.

Benefit:
Improves data security.

------------------------------------

4. Inheritance
- Allows one class to inherit features from another class.
- Helps reduce code duplication.

Benefit:
Code reusability.

------------------------------------

5. Polymorphism
- One method can perform different tasks.
- Achieved using method overloading and overriding.

Benefit:
Flexibility in programming.

------------------------------------

6. Abstraction
- Hides unnecessary implementation details.
- Shows only important information to users.

Benefit:
Reduces complexity.

------------------------------------

Advantages of OOP:
✔ Better code organization
✔ Easier maintenance
✔ Reusable code
✔ Improved security
✔ Real-world modeling support
